# Project 01 – Simple Calculator

## Description
A simple calculator developed using C programming. It performs basic arithmetic operations on two numbers, including addition, subtraction, multiplication, and division.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- User input and operation selection
- Division-by-zero handling

## Concepts Used
- Variables and data types
- `printf()` and `scanf()`
- Arithmetic operators
- Conditional statements / Switch
- User input and output

## Purpose
This project was developed to practice fundamental C programming concepts and improve logical thinking through a practical application.

**Language:** C
